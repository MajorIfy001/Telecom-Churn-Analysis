# ☎️Telecom Churn Analysis.
## 📌Overview
After a careful study and analysis of the data provided, it was deduced that the telecom company is experiencing a significant churn rate of 26.54%, with 1,869 customers churned out of a total customer base of 7,043. The total charges amount to $16M. The churn rate of 26.54% is concerning and suggests a need for better customer retention strategies.

## 🛠️Tools used
- Microsft Power BI for dashboard creation
- Power Query for data transformation in Microsoft Power BI
- DAX for advanced calculations in Microsoft Power BI

### 🧭Steps
- Step 1 : Load data into Power BI Desktop, dataset is a csv file.
- Step 2 : Open power query editor & in view tab under Data preview section, check "column distribution", "column quality" & "column profile" options.
- Step 3 : Also since by default, profile will be opened only for 1000 rows so you need to select "column profiling based on entire dataset".
- Step 4 : It was further cross-examined and it was observed that  in none of the columns; errors & empty values were present.
- Step 5 : The model view was used to explore the connection amoongst the various datasets for analysis.
- Step 6 : Varoius measures were created using DAX expressions to aid analysis such as "Customers", "Churned", "Churn rate" and "Total charges".
- Step  7: In the report view, under the view tab, theme was selected.
- Step 8 : Multiple card visuals were added to the canvas repersenting the measures created in step 6.
- Step 9 : Page 1 of the dashboard shows an overview of the Customers distribution, page 2 shows an overview of the churn analysis while page 3 shows an overview of the churn rate analysis.
- Step 10 : Various charts, tables and graphs were added to the canvas; each used to visualise a set of the analysis. 

## 📊 Key Metrics Tracked
- Customers: 7043
- Churned: 1869
- Churn Rate: 26.54%
- Total Charges: $16M
